How we decide

  • Event on a >10 MeV proton channel: Warning
  • Event on a >100 MeV proton channel: Critical
  • No event on those channels: OK

Sources: NOAA SWPC (solar radiation storms) and NASA SRAG (crew guidance). The Warning/Critical mapping is a team demo parameter. Details in docs/research.md.

Data: NASA DONKI SEP via api.nasa.gov
